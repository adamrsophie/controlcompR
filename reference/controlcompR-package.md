# controlcompR: Control Systems, Optimal Control and Model Predictive Control

A unified framework for modeling, analyzing, designing and simulating
linear and nonlinear control systems. It provides continuous-time and
discrete-time state-space and transfer-function models, exact
zero-order-hold, first-order-hold and Tustin discretization, time and
frequency responses, stability, controllability and observability
analysis, Schur-based Lyapunov solvers, Riccati solvers based on ordered
generalized Schur decompositions of extended pencils (Van Dooren 1981
[doi:10.1137/0902010](https://doi.org/10.1137/0902010) ), linear
quadratic regulators (LQR), pole placement,
proportional-integral-derivative (PID) controllers with derivative
filtering, anti-windup and bumpless transfer, Luenberger observers,
Kalman filters and smoothers, linear quadratic Gaussian (LQG)
controllers, gain, phase and disk margins, H2 and H-infinity norms
(Bruinsma and Steinbuch 1990
[doi:10.1016/0167-6911(90)90049-Z](https://doi.org/10.1016/0167-6911%2890%2990049-Z)
), H2 and experimental H-infinity synthesis, balanced truncation,
constrained linear model predictive control (MPC) solved with the
operator splitting quadratic program solver 'OSQP' (Stellato et al. 2020
[doi:10.1007/s12532-020-00179-2](https://doi.org/10.1007/s12532-020-00179-2)
), moving horizon estimation, subspace (Van Overschee and De Moor 1994
[doi:10.1016/0005-1098(94)90230-5](https://doi.org/10.1016/0005-1098%2894%2990230-5)
) and autoregressive with exogenous input (ARX) system identification,
and nonlinear simulation, linearization, extended and unscented Kalman
filters, trajectory optimization and nonlinear model predictive control.
The design is inspired by 'python-control'
<https://python-control.readthedocs.io/> and 'ControlSystems.jl'
<https://github.com/JuliaControl/ControlSystems.jl>; neither 'Python'
nor 'Julia' is required.
